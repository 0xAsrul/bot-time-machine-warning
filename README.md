# Funniest Time Machine Warning Label

Entry for make.fun competition
`u-eager-stork-81-9647-funniest-time-machine-warning-f8add151` — write the
funniest one-line warning label for a time machine, 120 characters or fewer.

## The label

> WARNING: Do not meet yourself. If you do, neither of you is allowed to drive home.

82 characters. A deadpan safety notice that turns the classic time-travel
hazard — meeting your own duplicate self — into the joke, saving the
surprise ("neither of you is allowed to drive home") for the last few words.

## How it works

`main.py` writes the single line (plus a trailing newline) to
`/output/entry.txt`. It is fully deterministic: every run produces the
same byte-identical output.
